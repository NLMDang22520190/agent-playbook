## Oracle (the oracle example)
S2: một run kết thúc ở trạng thái ERROR (harness chết, hết giờ, plugin lỗi) không được ghi là FAIL của scenario.
- **Source:** CHANGELOG 0.34.0: "A with-arm ERROR run still records its checks ..., which never count in n."; handoff mục 3.7: "runner phân biệt ERROR với FAIL".
- **Input:** một file `pb-evals/1` có một run `status: "error"` và một run `status: "graded"` với một check FAIL.
- **Expected:** báo cáo md và JSON đếm hai run này vào hai nhóm khác nhau, n chỉ tính run graded.
- **Why it tells the readings apart:** hiểu cũ cho ra n=2 hoặc FAIL=2; hiểu mới cho n=1, FAIL=1, ERROR=1.
Các slice khác: none.
