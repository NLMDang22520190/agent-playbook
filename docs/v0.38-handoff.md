## Cách chạy gate (đã trả giá để biết)
- Môi trường cloud: GraphQL bị chặn (`gh pr view` lỗi, dùng `gh api` REST), công cụ GitHub MCP đôi khi mất kết nối, không có khóa ký. `ship.sh` và `release.sh` không chạy trọn trong cloud (T11); chủ repo chạy local.
- Gate trả tiền chạy ở session local của chủ repo (gửi bằng `send_message` tới session "AI SLOP và AI SDLC", id `session_01TQoxUCbokT29CHLMUCCAkx`, nếu còn). Session local phải xin chủ repo xác nhận từng trần chi phí.
- `--max-cost` là **mỗi runner**, không phải tổng. Gate v0.37.0 tốn 56,93 USD ở lần pass, tổng bốn lần hỏng cộng thêm. Đặt trần rõ ràng và nói con số tổng.
- Sau khi chọn sha cuối cho gate: không commit hay merge gì vào nhánh đó (mỗi commit đổi sha và làm vô hiệu gate), ngoài `evals/results`. Pooling cần `playbook_commit == HEAD` (G4 sẽ đổi).
- Chạy `tools/replay-graders.sh` (miễn phí) trên transcript trước mọi gate trả tiền; hai trong bốn lần hỏng ở v0.37.0 là grader báo sai.
- Gate nhánh without chỉ tái dùng nếu baseline gate chưa quá 7 ngày; baseline v0.36 đã hết hạn từ 2026-11-23.
- CI: concurrency hủy lượt cũ khi push mới, nên aggregator đỏ do shard bị hủy không phải lỗi thật. Số test README do CI quyết định; `release-pr-check.sh` đòi commit rỗng `release: README test count N (verified)` sau mỗi lần test đổi (T12 sẽ bỏ). Suite local có khoảng 48 lỗi do môi trường (T8): luôn đối chiếu với CI, không tin local xanh hay đỏ.

## Bẫy đã gặp
- Stray check chỉ thấy ghi vào thư mục cha của workdir; layout hiện tại `<root>/<label>/work` (dưới `--jobs N>1` là `.jobs/<label>`).
- `evals/transcript.js` ghi `<log>.result` rồi xóa nếu không có dòng result; công cụ replay phải làm việc trên bản sao tạm.
- Windows: ca INT (`test-release-gate-par`) và F3b (`test-evals-runner-b.sh`) thỉnh thoảng đỏ; một lần chạy lại được phép, đừng bỏ qua test.
- Đừng nói nguyên nhân hay cấu trúc dữ liệu từ trí nhớ: đọc file hoặc chạy lệnh trước (`L-0010`). Ví dụ `tree` trong `gate.json` là clean/dirty, không phải hash.
- Sửa một check sau khi thấy gate fail cần ghi CHANGELOG, đo bù và chủ repo duyệt bằng văn bản (T15).
